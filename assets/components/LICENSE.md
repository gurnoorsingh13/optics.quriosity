# Component drawings — licence and attribution

The SVG drawings in this folder are taken from **ComponentLibrary**, a library
of optical component drawings by **Alexander Franzen**.

- `b-bsp.svg` — beam-splitter cube
- `b-mir.svg` — mirror
- `b-phase.svg` — phase plate
- `c-laser1.svg` — laser
- `e-pd1.svg` — photodiode

They are licensed under the **Creative Commons Attribution-NonCommercial 3.0
Unported licence (CC BY-NC 3.0)**: https://creativecommons.org/licenses/by-nc/3.0/

What this means for this project:

- Credit must be given to Alexander Franzen (done here, in the app's About
  page and in the README).
- The drawings may not be used for commercial purposes. The MIT licence of the
  source code does **not** extend to these files.
- Anyone who wants to use the simulator commercially should replace these five
  files with drawings they are free to use, then run
  `python tools/build_component_art.py`.

The files are used unmodified. `scripts/ui/component-art.js` contains a
cleaned copy (editor metadata removed, gradient ids renamed) generated by
`tools/build_component_art.py`.
