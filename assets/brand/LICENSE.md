# The Quriosity name and logo

The name **Quriosity**, the product name **optics.quriosity** and the Quriosity logo (every file in this folder, and the packed copy in `scripts/ui/brand-art.js`) belong to the optics.quriosity team. All rights are reserved.

They are **not** covered by the MIT License that applies to the source code.

You may:
- keep them in unmodified copies of this project, and
- use them to refer to this project, for example in a talk, a paper or a link.

Please do not use them for your own fork, product or service, or in a way that suggests the team endorses it. If you publish a modified version, give it a different name and logo: replace the files in this folder and run `python tools/build_brand.py`.

## Files

| File | Use |
| --- | --- |
| `quriosity-logo-black.svg` | Full logo for light backgrounds (also read by `tools/build_brand.py`) |
| `quriosity-logo-white.svg` | Full logo for dark backgrounds |
| `quriosity-mark-black.svg` | The Q question-mark on its own (also read by `tools/build_brand.py`) |
| `quriosity-mark-white.svg` | The Q mark for dark backgrounds |
| `favicon.svg` | Browser-tab icon; switches between black and white with the system theme |
| `social-preview.png` | 1280 × 640 image for the GitHub repository's social preview |
